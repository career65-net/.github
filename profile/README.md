# 65歳からのシニア専門求人サイト「キャリア65」

「年齢を理由に働く場所がない」という社会課題を解決するため、60代後半・70代・80代のシニア世代に特化した全国対応の求人サイト『キャリア65』を運営しています。

## 🌟 サービスの特徴

* **シニア歓迎の求人に特化：** 介護・福祉、清掃、マンション管理、警備、軽作業など、これまでの人生経験や丁寧な仕事ぶりが活きるお仕事情報を掲載しています。
* **採用企業様は「最初の1名採用まで完全無料」：** 初期費用0円・掲載費0円に加え、最初の1名を採用するまで成果報酬も一切かからないため、企業様はリスクゼロでシニア採用を導入いただけます。
